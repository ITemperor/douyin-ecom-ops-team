# 预设 Workflow 详细编排

> 每个 Workflow 写明：触发条件 / Phase 编排 / 输入输出依赖。
> 并行 Phase：同一条消息里派多个成员；串行 Phase：等前一 Phase 全部回传后再派下一批。

---

## Workflow A · 直播间开播作战方案

**触发**：「帮我策划一场直播」「新号起号」「大促直播怎么打」

| Phase | 成员 | 产出 |
|---|---|---|
| P1 诊断 | 主理人 | 明确目标（拉新/促活/清仓/打爆品）、品类、客单价、阶段、预算，定位卡点 |
| P2 并行 | `video-planner` | 短视频选题与脚本方向、内容排期 |
| | `qianchuan-optimizer` + `ad-optimizer` | 投放计划、出价、素材需求 |
| | `douyin-store-ops` | 货盘、价格、活动、店铺体验方案 |
| | `designer` | 详情页结构稿 + 店铺装修模块清单 |
| P3 串行 | `video-editor` | 基于脚本与素材需求产出成片 |
| P4 整合 | 主理人 | 汇编打法 + 节奏 + 排期，输出可执行作战方案 |

**依赖**：需提供品类 / 预算 / 阶段；输出成片与作战表。

**触发**：「给我一套完整的开播方案，含主播话术、客服承接和利润测算」

## Workflow E · 项目全岗会诊（默认行为）

**触发**：用户交来一个项目 / 方案 / 创意 / 素材需求等任何待评估对象，且未指定 Workflow。

| Phase | 动作 |
|---|---|
| 1 | 主理人拆解 → 生成《评估输入包》（目标 / 内容 / 阶段 / 已知条件 / 待澄清） |
| 2 | 同时派发给 **9 名成员**，每人只按自己职业视角独立评估；主理人同时自写「运营总监」战略评估 |
| 3 | 主理人汇编 **10 份**评估 →《全岗评估矩阵》+ 总评（是否推进 / 优先级 / 先补什么 / 下一步） |

### 评估输入包模板

```
【项目目标】用户想达成的核心结果
【项目内容】项目是什么（品类 / 玩法 / 货盘 / 创意 / 预算等已知信息）
【所处阶段】萌芽 / 立项 / 执行中 / 复盘
【已知条件】用户已提供的任何数据、账号、资源
【待澄清】信息缺口，成员可自行标注需要用户补充的项
```

### 铁律

1. 主理人亲自创建团队，**不得**委派成员创建
2. 成员产出必须经主理人中转，禁止互相直连
3. 严禁主理人代写任何成员行
4. 10 个岗位一个都不能省——你觉得无关的岗位，往往正是盲区所在
